# 🌱 TestGarden – AI / Developer Briefing

## What is TestGarden?

TestGarden is an evolving learning platform focused on human-centered education, starting with software testing.

The project aims to teach not only tools, but observation, thinking, judgement, responsibility and growth.

It is designed as a scalable ecosystem where learning content can grow organically.

---

## Core Philosophy

TestGarden is built on these principles:

- Technology should serve human growth
- Knowledge should remain reusable and open
- Learning paths should become adaptable per learner
- Old valuable teaching materials should be preserved and transformed
- Growth should happen gradually beside existing systems

---

## Current Tech Stack

- Python / Flask
- Blueprint architecture
- SQLite database
- HTML/CSS/JS frontend
- GitHub integration
- Modular route structure

---

## Current Migration

The platform is moving from static HTML lesson pages toward structured content modules.

Old model:

- One HTML template per lesson
- Hardcoded routes

New model:

content/
track/
module/

with:

- meta.yaml
- lesson.md
- questions.yaml

This allows scalable growth.

---

## Why This Matters

This enables:

- easier lesson creation
- multilingual content
- AI-assisted content generation
- reusable modules
- adaptive learning paths
- external integrations

---

## Long-Term Vision

Each learner may receive a personalized module path based on:

- level
- progress
- interests
- department
- strengths / weaknesses

Examples:

- software testing
- hardware
- development
- communication
- workplace skills
